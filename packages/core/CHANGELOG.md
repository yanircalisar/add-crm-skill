# Changelog: add-crm-core

Each release says whether `npm run migrate` will write a new migration after updating.

## 1.0.0 — 2026-11-11
First release as a package (the CRM previously lived in the plugin's template and was copied into each project).
- `createCrm(model)` builds the Worker from a project's `crm.model.mjs`: custom objects, custom fields on standard
  objects, Opportunity stages, picklist values and navigation tabs, all validated with clear messages.
- Prebuilt interface in `dist/web`; navigation tabs come from the model, so custom objects get their own tab.
- `add-crm` command line: `migrate` (append-only migrations from the model), `check`, `seed-admin`.
- Vendor images and fonts are removed from the bundled design system stylesheet.
- Migration: none for new projects (the first `npm run migrate` writes `0001_init.sql`). CRMs generated by plugin
  2.x adopt the package once with `add-crm migrate --baseline` (the plugin does this when updating).
